# Lease Deed Generator — upload required files

The Bhachunda homepage now links to `/Bhachunda/lease-deed/index.html`.

To activate this generator, open this folder on GitHub, select **Add file → Upload files**, and upload the following five files from the supplied deployment ZIP's `lease-deed` folder:

- `index.html`
- `styles.css`
- `app.js`
- `jszip.min.js`
- `lease_deed_template.docx`

Commit to the `main` branch. The generator then opens at:
https://nakulkpadi.github.io/Bhachunda/lease-deed/index.html

**Do not upload** test/example lease deeds or real landowners' personal documents. Note this repository is public: its template file will also be publicly downloadable.

The original English and Gujarati lease clauses are preserved in the supplied source-based template. The base rent is INR 55,000/acre/year, the first two years are treated as advance, and the original five-percent escalation every three years is retained.
